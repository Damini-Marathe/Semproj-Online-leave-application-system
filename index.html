Welcome to Student Leave Application System

This system allows students to apply for leave online and easily check the status of their leave applications.

📝 Apply Leave

Students can submit their leave applications online with all required details.

📊 Track Status

Students can check whether their leave is Pending, Approved or Rejected.

👨‍💼 Admin Management

Admin can view applications and approve or reject student leave requests.

How It Works

  1. Student Login or Direct Apply
  2. Fill the Leave Application Form
  3. Submit the Leave Application to Cloud Database
  4. Admin Reviews and Approves/Rejects the Application
  5. Student Checks Leave Status Using PRN
